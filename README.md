# Phase 2 – 

## Overview
Phase 2 focuses on **Exploratory Data Analysis (EDA)** and **clustering** of the Benefits dataset to understand its distributions, relationships, and underlying patterns.

## 1D Analysis
- Summary statistics: Mean, Median, Minimum, Maximum, Range, Variance, Standard Deviation, IQR, Skewness, and Kurtosis.
- Frequency and relative frequency distributions.
- Histograms, bar plots, pie charts, and box plots.
- Outlier detection.

## 2D Analysis
- Contingency tables with row and column percentages.
- Grouped summary statistics for numerical variables across categories.
- Scatter plots with regression lines.
- Pearson and Spearman correlation.
- Side-by-side box plots, violin plots, and stacked/grouped bar plots.

## N-Dimensional Analysis
- Analysis using multiple categorical and numerical variables.
- Correlation matrix and heatmap.
- Category-wise correlation analysis.
- Faceted box plots and grouped bar charts with error bars.
- Pairs plot / scatterplot matrix for multiple numerical features.

## K-Means Clustering
- Selected numerical features and standardized the data.
- Applied K-Means clustering.
- Calculated WCSS for **K = 1 to 10**.
- Used the **Elbow Method** to determine the suitable number of clusters.
- Final clustering was performed with **K = 3**.

## Hierarchical Clustering
- Calculated Euclidean distances between observations.
- Applied Single, Complete, Average, and Ward linkage methods.
- Generated dendrograms for the different linkage methods.
- Final clustering was performed into **3 clusters using Ward's method**.

## Conclusion
Phase 2 combines **1D, 2D, and N-dimensional EDA** with **K-Means and Hierarchical Clustering** to identify distributions, relationships, correlations, and natural groupings within the dataset.
